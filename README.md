# AI 选品工作台与抖音采集工具

选品工作台、Android 手机采集应用和抖音商品采集脚本的源码。

| 目录 | 内容 |
| --- | --- |
| [ai选品工作台](ai选品工作台/README.md) | Web 工作台、商品库、手机配对与任务管理 |
| [手机商品采集](手机商品采集/README.md) | Android 无障碍采集应用、构建脚本与导出工具 |
| [抖音商品采集](抖音商品采集/README.md) | 考古加列表及素材采集、抖音手机端规格报价采集与结果合并 |
| 采集工具 | 公共采集辅助脚本 |

## 开始使用

工作台：进入 `ai选品工作台`，执行 `npm ci`、`npm run dev`。手机配对、HTTPS 网关及数据接口见该目录的说明。

Android 应用：进入 `手机商品采集`，执行 `./build.ps1`。需要本机 JDK 与 Android SDK，详细参数见应用说明。

采集脚本：进入 `抖音商品采集`，执行 `python -m pip install -r requirements.txt`，按说明连接已授权的手机和已登录的浏览器。

数据库、采集结果、登录配置、应用签名、依赖及构建产物保留在本机，不提交到仓库。全新环境需要重新配置登录和应用签名；更新已安装的 Android 应用时须继续使用原来的本机签名。
